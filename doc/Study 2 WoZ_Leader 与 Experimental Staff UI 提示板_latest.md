# Study 2 WoZ：Leader 与 Experimental Staff UI 提示板（Leader Episode 拆分 + 全中文新版）

## 0. 使用说明

本文件提供可以直接粘贴到 UI 面板中的三类提示板内容：

1. **Leader Trial 提示板**：每个 trial 开始前给 leader 查看，说明本 trial 的整体任务、items，以及每个 episode 对应讨论的 item。
2. **Leader Episode 提示板**：每个 episode 开始前给 leader 查看，说明当前 episode 需要围绕哪些 items 做什么，以及 leader 应如何引导讨论。
3. **Staff Episode 提示板**：每个 episode 给 experimental staff 查看，说明当前 episode 的讨论任务、discussion focus，以及每位 staff 的角色任务。

提示板不是逐句台词，而是用于保证每个 trial / episode 的讨论结构一致。Leader 和 experimental staff 都应自然讨论，不需要背固定台词。


你的角色：
你是 leader。请引导小组讨论，解释或总结当前 item，并在合适时机把发言机会交给可能想补充观点的成员。

本 trial 目标：
讨论前四个荒岛求生 items，并判断它们的相对重要性。

# Block 3：Silence Context — 深山求生

## Block 3 修改后的执行逻辑说明

```text
Block 3 不再要求 leader 和 staff 人为表演“大家突然完全沉默”。
更合理的做法是将 Silence Context 设计为“讨论自然收束后的过渡与重启”。

具体执行方式：
1. 每个 episode 仍然围绕一个明确的 survival item 展开讨论。
2. Staff 需要正常讨论当前 item，不需要故意长时间沉默。
3. 当一个观点自然结束后，staff 可以用较短回应、确认、犹豫或等待 leader 分配话轮的方式制造“讨论需要推进”的状态。
4. Target member 并不是完全不说话的人，而是“有下一个推进点、总结点或补充点，但尚未被 leader 邀请的人”。
5. Leader 的任务不是等待尴尬沉默，而是在讨论自然收束、话轮交接不明确、或系统提示出现时，邀请合适成员继续推进。

这样可以避免实验中出现不自然的集体沉默，同时仍然测试 leader 是否能够利用 feedback 来恢复讨论节奏、分配下一轮发言机会。
```
